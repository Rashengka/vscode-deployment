# OpenSSH test vectors

These files are copied unchanged from OpenSSH portable
(<https://github.com/openssh/openssh-portable>), commit
`268bdcb0c80876d97abdc74a1ca8992a1fdf7652`:

| File here       | Upstream path                                     |
| --------------- | ------------------------------------------------- |
| `known_hosts`   | `regress/unittests/hostkeys/testdata/known_hosts` |
| `ed25519_1.pub` | `regress/unittests/sshkey/testdata/ed25519_1.pub` |
| `ed25519_1.fp`  | `regress/unittests/sshkey/testdata/ed25519_1.fp`  |
| `ecdsa_1.pub`   | `regress/unittests/sshkey/testdata/ecdsa_1.pub`   |
| `ecdsa_1.fp`    | `regress/unittests/sshkey/testdata/ecdsa_1.fp`    |
| `rsa_1.pub`     | `regress/unittests/sshkey/testdata/rsa_1.pub`     |
| `rsa_1.fp`      | `regress/unittests/sshkey/testdata/rsa_1.fp`      |

They were generated by the real `ssh-keygen` (the hashed host names with `ssh-keygen -H`), so
the tests compare this extension against OpenSSH rather than against itself.

The OpenSSH regression tests are placed in the public domain. Public keys only.
